# TwitchVODEnhancer

[English](README.md) | **Русский**

Userscript, который добавляет **тепловую карту активности чата** под полосу прокрутки VOD на Twitch. Тёплые цвета (жёлтый, красный) отмечают моменты, где в чате много сообщений, холодные (бирюзовый, чёрный) — где тихо. Так можно сразу перейти к самым интересным частям стрима.

Это переписанная в 2026 году версия [sooqua/TwitchVODEnhancer](https://github.com/sooqua/TwitchVODEnhancer) (2017). Оригинал перестал работать после редизайна плеера Twitch и отключения Kraken API и сервиса `rechat`.

## Возможности

- Загрузка по запросу: в панели плеера слева от **Clip** появляется кнопка **Get heatmap**. Пока её не нажать, никаких запросов не делается (`autoLoad: true` включает автоматическое построение). При ошибке кнопка превращается в **Retry heatmap**.
- Полоса тепловой карты прямо под штатной полосой прокрутки, синхронизированная с таймлайном VOD (по умолчанию 1 столбец = 1 минута).
- Подсказка при наведении с уровнем активности и количеством сообщений в этот момент:

  | Подсказка | Значение |
  |---|---|
  | чат молчал | сообщений нет |
  | тихо | ниже 0.5× обычного уровня |
  | обычная активность | 0.5×–1.5× |
  | чат активен | 1.5×–3× |
  | всплеск активности 🔥 | выше 3× |

  «Обычный уровень» — медиана по всем минутам VOD, где был хотя бы один комментарий, поэтому шкала подстраивается и под небольшие, и под очень активные стримы.
- Клик по тепловой карте перематывает видео, как обычная полоса прокрутки.
- Карта заполняется по мере загрузки. Над полосой прокрутки показывается индикатор (`chat: 66% · 5 406 msgs`), который исчезает через 15 секунд после достижения 100%.
- Параллельная загрузка: VOD на ~5 часов с ~10 тыс. сообщений обрабатывается примерно за 15–20 секунд.
- Поддержка SPA‑навигации Twitch: при переходе между VOD карта пересобирается, уже загруженные VOD кешируются на время сессии.
- **Не нужны ни Client ID, ни регистрация приложения в API.**

## Установка

1. Установите менеджер userscript'ов, например [Tampermonkey](https://www.tampermonkey.net/).
   В Chrome 138+ дополнительно откройте `chrome://extensions` → Tampermonkey → **Сведения** и включите **Разрешить пользовательские скрипты** (Allow User Scripts).
2. Откройте [`TwitchVODEnhancer.user.js`](TwitchVODEnhancer.user.js), нажмите **Raw** и подтвердите установку.
3. Откройте любой VOD (`https://www.twitch.tv/videos/...`) и нажмите **Get heatmap** слева от **Clip** — тепловая карта появится под полосой прокрутки.

Если у вас установлена старая версия 2017 года, сначала отключите или удалите её.

## Как это работает

Публичного API для повтора чата VOD у Twitch больше нет: Kraken отключён в 2022 году, а в Helix эндпоинта комментариев не существует. Единственный рабочий источник — внутренняя GraphQL‑операция `VideoCommentsByOffsetOrCursor`, которой пользуется сам плеер Twitch. Она требует токен `Client-Integrity`, который нельзя сгенерировать вне браузера.

Поэтому скрипт:

1. Перехватывает `window.fetch` на этапе `document-start` и копирует заголовки (`Client-Id`, `Client-Integrity`, `Authorization` и др.) и хеш persisted query из собственных GQL‑запросов Twitch.
2. Получает длительность VOD и делит видео на сегменты, которые загружаются параллельно через пагинацию по курсору.
3. Считает сообщения по временным интервалам и рисует тепловую карту на `<canvas>`, прикреплённом к `[data-a-target="player-seekbar"]`.

Заголовки вашей сессии отправляются только на `gql.twitch.tv` — тот же сервер, к которому и так обращается Twitch; третьим сторонам ничего не передаётся. Запросы самой страницы проходят через перехватчик без изменений.

> ⚠️ Скрипт опирается на недокументированный внутренний API и текущую разметку плеера. Twitch может изменить и то, и другое в любой момент.

## Настройка

Отредактируйте объект `CFG` в начале скрипта:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `binSec` | `60` | Ширина одного столбца тепловой карты, сек |
| `stripHeight` | `6` | Высота полосы тепловой карты, px |
| `hitPad` | `3` | Дополнительная зона наведения сверху/снизу полосы, px |
| `labelOffset` | `22` | На сколько выше полосы прокрутки показывать индикатор загрузки, px |
| `labelHideDelay` | `15000` | Скрыть индикатор загрузки через N мс после 100% |
| `concurrency` | `4` | Количество параллельных загрузчиков |
| `reqDelay` | `60` | Пауза между запросами внутри одного загрузчика, мс |
| `percentile` | `0.98` | Перцентиль для нормализации цвета, чтобы один всплеск не «гасил» остальное |
| `autoLoad` | `false` | Строить тепловую карту автоматически при открытии VOD, без кнопки |
| `debug` | `true` | Выводить сообщения `[TVE]` в консоль |

## Диагностика

Откройте DevTools → Console на странице VOD и найдите сообщения `[TVE]`. Нормальный запуск выглядит так:

```
[TVE] headers captured: client-id, client-integrity, authorization, ...
[TVE] video 2889043122
[TVE] duration 17522 s
[TVE] heatmap attached below seekbar
[TVE] done: 9766 msgs in 16.8s
```

| Симптом | Вероятная причина / решение |
|---|---|
| Нет строки `headers captured` | Скрипт работает не в контексте страницы. Проверьте, что менеджеру разрешено запускать пользовательские скрипты и что у скрипта стоит `@grant none`. |
| `unexpected response: …` | Twitch изменил формат ответа GQL. Создайте issue со строкой из лога. |
| Много строк `retry …` | Ограничение частоты запросов. Уменьшите `concurrency` до 2 или увеличьте `reqDelay`. |
| Красный текст `TVE: …` над полосой прокрутки | Загрузка не удалась; текст ошибки показан там и в консоли. |
| Тепловая карта перекрывает кнопки или подписи плеера | Подберите `stripHeight`, `hitPad` или `labelOffset`. |

Сообщения вида `s.amazon-adsystem.com … ERR_CONNECTION_RESET` с `window.fetch @ userscript…` в стеке — это собственные (заблокированные) рекламные запросы Twitch, проходящие через перехватчик, а не ошибки скрипта.
